# La Galerie Moema

Landing page premium em Next.js 15, TypeScript, SCSS Modules, Bootstrap Grid, Framer Motion e Swiper.

## Rodar localmente

```bash
npm install
npm run dev
```

Depois acesse `http://localhost:3000`.

## Estrutura

- `app`: App Router, metadata, sitemap e robots
- `components`: elementos reutilizáveis
- `sections`: blocos editoriais da landing page
- `styles`: tokens visuais e estilos globais
- `assets`: pasta reservada para renders finais do empreendimento
